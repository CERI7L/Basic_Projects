Purpose
This repository documents my development from basic programming exercises toward the knowledge and practical skills expected of a junior developer. Each project represents a stage in that journey: a new concept introduced, a problem explored, or an opportunity to apply earlier lessons in a more creative way.

My aim is to show both working examples and increasing understanding of the code behind them. As I progress, I will add lesson submissions, improve existing projects, and build new projects that demonstrate creative initiative and the practical application of what I am studying.
Curriculum and lesson submissions
The curriculum is in the file beginning with 00_, listed above this README in the repository. It provides the structure for reviewing my projects line by line and studying the terms, functions, methods, operators, and calls used throughout them.

I will use this curriculum to guide my lesson submissions. Each submission will aim to include:
- The topic studied and the relevant project or code section.
- An explanation of what the code does and why it works.
- A modification or exercise that applies the lesson.
- Examples of expected results, errors encountered, and corrections made.
- Notes on anything I still need to review or practise.
My goal is to move from recognising code to explaining, debugging, adapting, and independently rebuilding it.

Current learning stage
My foundation is developing through input and output, variables, conditions, loops, basic functions, and HTML/CSS presentation. More recent projects introduce libraries, structured data, parsing, browser events, asynchronous operations, and interaction between languages.

These newer topics still need deliberate review and hands-on experience. A working result is a starting point: I want to be able to explain the execution flow, identify limitations, make changes confidently, and reproduce the important ideas in a different project.
Next steps toward junior developer skills
As my understanding grows, I intend to:
1. Complete and submit lessons based on my Python_PortfolioCurriculum.md
2. Revisit early projects to improve validation, readability, structure, and error handling.
3. Build original variations that combine previous lessons and introduce a manageable new challenge.
4. Develop stronger habits in debugging, testing, Git version control, dependency management, and documentation.
5. Progress toward larger projects with reusable components, clearer requirements, and evidence that their behaviour has been checked.
Creative initiative is central to this process. I want future projects to demonstrate that I can take a lesson, understand its purpose, and apply it to an idea of my own. This repository will grow alongside that understanding, preserving my early work while documenting the steps toward junior developer capability.
